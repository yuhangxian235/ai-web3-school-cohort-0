## 📝 3 个问题 + 答案

### ① 为什么通用 AI 不知道 gas 价格 / 余额？链感知上下文解决了什么？

通用 AI（GPT/DeepSeek）的知识是训练时冻结的，没有实时链上数据。链感知上下文的解决方案：**在每次 AI 调用前，系统自动拼好一个结构化上下文包**（chain id + 余额 + gas + 授权 + 最近交易 + citation），AI 只需要读，不需要"猜"。

### ② StablePay AI 助手转账需要的链上实时信息（6 个）

| # | 信息 | 为什么需要 |
|---|------|-----------|
| 1 | 对方地址有效性 | EOA 还是合约？会不会 revert？ |
| 2 | 当前 gas 价格 | 太高亏 gas，太低可能卡住 |
| 3 | 用户余额（ETH + ERC20） | 余额不够直接失败 |
| 4 | nonce | nonce 错了交易卡住或被抢跑 |
| 5 | ERC20 allowance | 授权额度不够会 revert |
| 6 | chain ID | 防止发到错误链（重放攻击） |

### ③ 2 分钟旧数据的风险 & 解决方案

**风险**：
- 滑点超出容忍上限 → 被 MEV 夹
- 余额 2 分钟前够、现在不够 → 交易失败白花 gas
- 授权状态过期 → revert

**解决方案**：**在执行前一刻调用 RPC/工具获取实时数据，不缓存旧数据**。每条上下文带时间戳 + block number，过期即失效。

## 💡 核心收获

链上状态 3 个特性：
1. **时效性** — 同一地址的余额/授权随区块变化
2. **来源可追溯** — 每条结论必须带 tx hash / block number / explorer link
3. **事实 vs 解释** — 工具返回事实，模型负责解释，不能混

没有 citation 的链上解释 = 观点，带 citation = 可验证。
